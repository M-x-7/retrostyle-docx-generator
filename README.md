# 復古風DOCX生成工具

在瀏覽器裡填欄位，套用自己的 Word 範本（.docx）產生文件；也可以先在現場照片上畫線、加文字與符號，再一起放進文件。

- **不用安裝、不用網路**：直接開 `index.html`，或用 GitHub Pages 的網址。
- **資料不上傳**：照片、範本、填寫內容都只在你的瀏覽器裡處理。
- **欄位規則寫在範本裡**：換一份範本就換一整套欄位，不用改程式。
- **復古風介面**：暗色的 Windows 95 風格視窗、按鈕與對話框。

## 開始使用

1. 打開網頁，或把整個資料夾（`index.html`、`favicon.ico`、`css/`、`js/`）複製到電腦，再用瀏覽器開 `index.html`。
   需要 Edge 或 Chrome 103 以上。
2. 按「填寫文件…」或「匯出 Word…」，選擇你的 Word 範本（.docx）。範本會記在瀏覽器裡，下次不用再選。
   還沒有範本的話，先下載 [範例範本.docx](範例範本.docx) 試用，它示範了下面所有的寫法，也可以直接改成你自己的。
3. 填好欄位，按「產生 .docx」。

要放照片的話，先用「照片」匯入（可多選、可拖曳進視窗、可 Ctrl+V 貼上），在照片清單按右鍵設定照片的用途。

## 照片標註

| 操作 | 方式 |
|---|---|
| 畫線 | 按住線型的快捷鍵點照片放點、拖曳手繪；按住期間畫的全部接成一條線，放開按鍵完成 |
| 放文字 | 按住文字樣式的快捷鍵（預設 Q）點照片，放開按鍵再打字；Shift+Enter 換行，選取文字後可在樣式區改對齊（靠左／置中／靠右） |
| 放符號 | 按住符號的快捷鍵（預設 1–6）點照片；按住滑鼠拖曳可決定方向 |
| 選取、移動 | 放開所有快捷鍵就是選取模式：點項目選取、拖曳移動、Delete 刪除 |
| 縮放、旋轉 | 選取文字或符號後，拖右下角方塊縮放、拖外側圓點旋轉 |
| 複製標註 | 選取後 Ctrl+C，在這張或別張照片 Ctrl+V 貼上；Ctrl+D 原地複製一份 |
| 復原、重做 | Ctrl+Z；Ctrl+Y 或 Ctrl+Shift+Z |
| 放大縮小照片 | 滾輪以游標為中心縮放，中鍵或右鍵拖曳平移；點狀態列的比例或 Ctrl+0 回到整張 |
| 旋轉、裁切照片 | 在照片清單按右鍵：向左／向右轉 90°、裁切…（拖曳框出要留下的範圍）；標註會跟著換算 |

線型、文字樣式、符號（形狀、顏色、描邊、快捷鍵）都可以在「線型/文字/符號設定…」裡自訂，
也可以用「設定檔…」匯出、再到別台電腦匯入。

專案（照片＋標註＋填寫內容）用「儲存」存成一個 .json 檔，之後用「開啟」繼續編輯。
還沒存的工作每 15 秒會自動暫存在瀏覽器裡；瀏覽器當掉或電腦重開後再打開，會問要不要還原。

## 製作範本

範本就是一般的 Word 檔，在要填資料的地方放 `{{標記}}`：

| 標記 | 意思 |
|---|---|
| `{{名稱}}` | 文字欄位，匯出時換成填寫的內容 |
| `{{名稱*}}` | 同上，而且是必填 |
| `{{□群組:選項}}` | 勾選框，勾選印出 ■，否則 □ |
| `{{圖:名稱}}` | 單獨一段：放入用途是「名稱」的照片 |
| `{{現場照片}}` | 單獨一段：依清單順序放入所有現場照片，每列 2 張 |
| `{{現場照片:3}}` | 同上，每列 3 張（數字幾就幾張） |

同一個標記可以放好幾次，填一次就全部填上。Word 把標記拆成好幾段格式也沒關係。
匯出視窗的「照片的文繞圖」套用在 `{{現場照片}}` 排出的照片；`{{圖:名稱}}` 的照片一律跟文字排列。

### 範本設定表

在範本最後放一張表格，**第一列只寫「範本設定」**，第二列是欄名，之後一列一個欄位。
欄名順序不拘；其他欄名（例如範例範本裡的「備註」）會被略過，可以拿來寫說明。
匯出時這張表會整張刪掉，不會印出來。沒有這張表也能用，所有欄位都當一般文字。

| 欄位 | 類型 | 選項 | 預設值 | 必填 |
|---|---|---|---|---|
| 日期 | 月日 | | | ✔ |
| 狀態 | 選項 | 待處理/處理中/已完成 | | |
| 說明 | 多行 | | | |
| 單號 | 流水號 | 3 | | ✔ |
| 編號 | 數字 | | | |
| 填表日 | 文字 | | `{今天}` | |
| 標題 | 文字 | | `={地點}工作紀錄（{狀態}）` | |
| 分區 | 對照 | `01=北區/02=北區/03=南區` | `{編號}` | |
| 檔名 | | | `{單號}-{標題}` | |

**類型**

| 類型 | 輸入方式 |
|---|---|
| 文字 | 一般輸入格（類型空白也是文字） |
| 多行 | 可以換行的輸入格 |
| 數字 | 只收數字，全形數字自動轉半形 |
| 月日 | 打 4 碼數字，自動變成 `12/31` |
| 流水號 | 分成「西元日期 8 碼」＋「流水號」兩格，流水號可用 ▲▼ 加減；「選項」寫碼數，空白＝3 |
| 選項 | 一排選鈕，選項用 `/` 分隔或一行一個；寫成 `標籤=實際文字` 時按鈕顯示標籤、文件裡印實際文字 |
| 對照 | 不顯示在畫面上，自動算：把「預設值」展開後，跟選項的標籤比開頭，例如編號 `0215` 對到 `02=北區` |

**預設值**：開啟匯出視窗時欄位空白就自動帶入。

- 一般寫法在帶入當下就固定，例如 `{今天}` 會記下填寫那天的日期。
- **以 `=` 開頭是公式**，欄位裡保留 `{名稱}`，下方即時顯示結果，引用的欄位改了會跟著變。

**必填**：有寫東西（例如 ✔）就是必填，沒填會擋下來不讓匯出。

**候選**（選用的欄名）：一格裡每一行是一句候選文字（在 Word 裡按 Enter 分段或 Shift+Enter 換行都可以），
匯出視窗裡這個欄位旁的 ▾ 會列在最上面，點一下整欄換成那一句，適合放常用的罐頭語。例如「地點」的候選格寫「一樓大廳／頂樓機房／地下停車場」三行。

**其他規則**

- 設定表裡有、範本內文沒有的欄位，會出現在匯出視窗上方的「自訂欄位」，只用來給其他欄位引用，不印出來。
- 勾選框的群組名和某個欄位同名時（例如 `{{□分區:北區}}` 和對照欄位「分區」），會依那個欄位自動勾選，畫面上不顯示。
- 「檔名」那一列不是欄位，它的預設值是匯出檔名；沒有這一列就叫「文件」。
- 載入範本時，類型寫錯、引用了不存在的欄位等問題會跳提示。

### 在欄位裡引用其他內容

欄位的值、預設值、選項裡都可以寫 `{名稱}`，匯出時換成對應的內容：

| 寫法 | 換成 |
|---|---|
| `{欄位名}` | 那個欄位目前的值 |
| `{今天}` / `{今天西元}` / `{今天月日}` | `115.11.03` / `20261103` / `11/03` |
| `{常用字串名}` | 「常用字串…」裡自己存的片語（只存在這台瀏覽器） |
| `{欄位=值?是:否}` | 條件，例如 `{狀態=已完成?完成作業:進行作業}`；兩邊都可以留空，`＝？：` 寫成全形也可以 |

引用的欄位沒填時，後面緊跟的一個空白會一起消失，句子開頭不會留空格。認不得的 `{…}` 會原樣留著，方便發現打錯字。

## 資料存在哪裡

- 線型、文字樣式、符號、工具列設定、常用字串、填過的欄位值：瀏覽器的 localStorage。
- 範本、自動暫存的工作：瀏覽器的 IndexedDB。
- 不同瀏覽器、不同電腦各自分開；清除瀏覽器資料就會不見。線型等設定可以用「設定檔…」匯出備份。
